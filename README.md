# chrisye2020-art.github.io

Personal website for Christopher Ye — B.S. Business Administration (Finance), minors in
Artificial Intelligence and Robotics, Carnegie Mellon University, Class of 2029.

**Live site:** https://chrisye2020-art.github.io

## Stack

Static site, no build step. Plain HTML, CSS and vanilla JavaScript, served by GitHub Pages.

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and the inline SVG icon sprite |
| `styles.css` | Styling, light/dark theming, responsive layout |
| `app.js` | Scroll reveals, nav highlighting |
| `img/` | Photographs |
| `img/logos/` | Organisation logos |

## Editing

Edit the files directly and commit to `main`; GitHub Pages redeploys automatically.
